# Releasing a new 0bull Cast build to AltStore PAL

Repeatable runbook for an agent. The public host (this repo, `TapTox/0bull-altstore`)
and `source.json` already exist — a new release only appends a version.

## Fixed facts (do not re-derive)

| Thing | Value |
|-------|-------|
| App bundle id | `com.zerobull.cast` |
| Apple item id / **marketplaceID** | `6796816526` (constant for this app) |
| App source repo (private) | `TapTox/0bull-next` |
| Public host repo | `TapTox/0bull-altstore` |
| Source URL users add | `https://taptox.github.io/0bull-altstore/source.json` |
| ASC API key | `~/.appstoreconnect/private_keys/AuthKey_Q5W7P3393N.p8`, Key ID `Q5W7P3393N`, Issuer `7b5fc53c-ffcb-449e-8480-ac43770c1579` |
| Dev team | `2NYMXZBKZ8` |
| Distribution cert expected by profiles | `iPhone Distribution: NANIMAD, S.L. (2NYMXZBKZ8)` |

## Why two repos

`0bull-next` is **private** — GitHub Release assets there are not publicly fetchable,
so AltStore users would 404. All ADP assets + `source.json` MUST live in the public
`0bull-altstore` repo.

## Steps

### 1. Build + upload to App Store Connect
The ADP is generated by Apple *after* a build is uploaded and processed. From
`0bull-next/ios/0bullCast` on the release commit:

```bash
xcodegen generate
BUILD=$(git rev-list --count HEAD)          # monotonic build number
KEY=~/.appstoreconnect/private_keys/AuthKey_Q5W7P3393N.p8
xcodebuild archive -project 0bullCast.xcodeproj -scheme ZeroBullCast \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath /tmp/0bullCast.xcarchive -allowProvisioningUpdates \
  -authenticationKeyPath "$KEY" -authenticationKeyID Q5W7P3393N \
  -authenticationKeyIssuerID 7b5fc53c-ffcb-449e-8480-ac43770c1579 \
  DEVELOPMENT_TEAM=2NYMXZBKZ8 MARKETING_VERSION=<X.Y> CURRENT_PROJECT_VERSION=$BUILD
xcodebuild -exportArchive -archivePath /tmp/0bullCast.xcarchive \
  -exportPath /tmp/export -exportOptionsPlist ExportOptions.plist \
  -allowProvisioningUpdates -authenticationKeyPath "$KEY" \
  -authenticationKeyID Q5W7P3393N -authenticationKeyIssuerID 7b5fc53c-ffcb-449e-8480-ac43770c1579
```
`ExportOptions.plist`: `method=app-store-connect`, `destination=upload`,
`teamID=2NYMXZBKZ8`, `signingStyle=automatic`, `manageAppVersionAndBuildNumber=false`.

Gotchas learned:
- Each upload needs a **unique, higher** build number, and marketing version must be
  **higher than the last approved** (train `1.0` is closed → use `1.1`, `1.0.1`, …).
- Info.plist already carries `NSCameraUsageDescription`, `NSMicrophoneUsageDescription`
  (ITMS-90683) and `ITSAppUsesNonExemptEncryption=false`. Keep them.

### 2. Enable alternative distribution + get the ADP ID
In App Store Connect the build must be **notarized / selected for alternative
distribution**. Grab that build's **ADP ID** (ASC UI, or webhook). Call it `ADP_ID`.

### 3. Fetch the ADP (AltStore REST API)
```bash
curl -s -X POST https://api.altstore.io/adps -H 'Content-Type: application/json' \
  -d "{\"adpID\":\"$ADP_ID\"}"                       # trigger processing
curl -s https://api.altstore.io/adps/$ADP_ID          # poll: status=="success" -> downloadURL
```
The `downloadURL` is an Azure SAS link that **expires in ~10 minutes — download NOW**:
```bash
curl -sL "<downloadURL>" -o adp.zip && unzip -o adp.zip -d adp
# adp/manifest.json  adp/signature  adp/variant/<publicId>.ipa (one per device variant)
```
NEVER modify `manifest.json` (no prettify). Read from it:
`bundleId`, `shortVersionString`, `bundleVersion`, `minimumSystemVersions.ios`,
and each `variants[].publicId` / `assetPath`.

### 4. Publish assets to the public release
Release assets are **flat** (no subdirs); the variant filenames are unique UUIDs.
```bash
TAG=adp-<X.Y>-<build>
gh release create "$TAG" --repo TapTox/0bull-altstore \
  --title "0bull Cast <X.Y> (ADP)" --notes "..." \
  adp/manifest.json adp/signature adp/variant/*.ipa \
  /path/to/icon_1024.png
```

### 5. Prepend a version entry to source.json
`versions` is **newest-first**. Add the new entry at index 0; keep old ones.
Base = `https://github.com/TapTox/0bull-altstore/releases/download/$TAG`.
For the entry:
- `version`/`marketingVersion` = manifest `shortVersionString`, `buildVersion` = manifest `bundleVersion`
- `minOSVersion` = manifest `minimumSystemVersions.ios`
- `downloadURL` = `$BASE/manifest.json`
- `assetURLs` = `{ manifest:$BASE/manifest.json, signature:$BASE/signature, <publicId>:$BASE/<publicId>.ipa … }`
- `size` = size of one variant .ipa
- Keep app-level `marketplaceID: "6796816526"`.

Then:
```bash
git -C 0bull-altstore add source.json && git -C 0bull-altstore commit -m "Add <X.Y> (build)" && git -C 0bull-altstore push
```

### 6. Verify (unauthenticated)
```bash
curl -sL -o /dev/null -w '%{http_code}\n' https://taptox.github.io/0bull-altstore/source.json
curl -sL "$BASE/manifest.json" | cmp -s - adp/manifest.json && echo "manifest identical"
curl -sL -o /dev/null -w '%{http_code}\n' "$BASE/<publicId>.ipa"
```
All 200, manifest byte-identical → AltStore PAL will serve the new build.
