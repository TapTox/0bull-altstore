# 0bull — AltStore PAL source

AltStore PAL distribution source for **0bull Cast** (`com.zerobull.cast`).

## Add this source

```
https://raw.githubusercontent.com/TapTox/0bull-altstore/main/source.json
```

Open that URL in AltStore PAL, or paste it under **Sources → Add Source**.

App binaries (the notarized Alternative Distribution Package: `manifest.json`,
`signature`, and per-device `variant/*.ipa`) are attached to the `adp-1.0`
GitHub Release. `manifest.json` is hosted byte-for-byte as produced by Apple —
do not modify it.
